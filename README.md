# ⛵ Terme-Regatta

Lern-App für **Terme und Gleichungen** (Klasse 8, Realschule): Ausmultiplizieren, Ausklammern, Summen multiplizieren, binomische Formeln, Faktorisieren, Gleichungen mit Klammern, Bruchgleichungen.
Fünf Regatten auf dem Untersee – an jeder Boje eine Aufgabe; falsch gelöst gibt es einen Strafkringel, den Lösungsweg und eine neue, ähnliche Aufgabe.

**Spielen:** https://maltefehling.github.io/terme-regatta/

| Regatta | Inhalt |
|---|---|
| 1 Clubregatta Gaienhofen | Ausmultiplizieren, Ausklammern |
| 2 Untersee-Cup | Summen multiplizieren, binomische Formeln, Kopfrechnen mit Binomen |
| 3 Bodensee-Woche | binomische Formeln mit Zahl vor der Variablen, Faktorisieren, Mittelstück prüfen |
| 4 Rund um die Höri | Gleichungen mit Klammern, Minus vor der Klammer, Bruchgleichungen |
| 5 Bodensee-Meisterschaft | verknüpfte Aufgaben: erst ausklammern dann faktorisieren, zwei Binome, Flächeninhalt als Term, Bruchgleichungen mit x im Zähler |

- Taschenrechner ist überall erlaubt. Bruchgleichungen lassen sich ohne Strafe gegen eine andere Aufgabe tauschen.
- Alle Aufgaben werden per Zufall neu erzeugt – keine Aufgaben aus Schulbüchern. Eine Datei, läuft offline, keine Daten verlassen das Gerät.
- Lehrkraft-Modus: `?alle` schaltet alle Regatten frei.

Aufbau wie die [Wurzel-Regatta](https://github.com/maltefehling/wurzel-regatta). Lizenz: MIT
